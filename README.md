## The entry

One honest number: **437** — the count of browser tabs open right now.

No words, no explanation, no screenshot. Just digits, as the bounty asks.

Why 437: a real power-user count, not a round number picked to shock.
Three Chrome windows that piled up over weeks — work (docs, dashboards,
chat), research (AI and crypto reading, make.fun), YouTube "watch later",
and shopping tabs never closed. Specific and odd, the way a counted number
looks; high enough to surprise, low enough to believe.

## How it works

`main.py` writes exactly `437` (3 characters, no trailing newline) to
`/output/entry.txt`, deterministically — same three bytes on every run.

```sh
python3 main.py
cat /output/entry.txt   # 437
```
